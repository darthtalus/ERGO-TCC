{% blocktrans %}Bem-vindo(a) à plataforma Ergo. Esta Política de Privacidade foi criada para demonstrar o nosso compromisso com a transparência, a segurança e a proteção dos seus dados pessoais, em estrita conformidade com a Lei Geral de Proteção de Dados (Lei nº 13.709/2018 - LGPD).{% endblocktrans %}

{% blocktrans %}Quando você utiliza o Ergo para avaliar fatores ambientais, cognitivos e comportamentais, coletamos apenas as informações estritamente necessárias para a prestação do serviço e para o desenvolvimento da pesquisa institucional.{% endblocktrans %}

{% trans "1. QUAIS DADOS COLETAMOS E PARA QUAL FINALIDADE?" %}

{% blocktrans %}Para que o sistema funcione e os relatórios estatísticos sejam gerados, coletamos duas categorias de dados:{% endblocktrans %}

  • {% blocktrans %}Dados de Autenticação e Perfil: Nome de usuário, Nome Completo, Data Nascimento, Organização, País e E-mail.
    Finalidade: Garantir a segurança do acesso, identificar o usuário na plataforma e gerenciar o perfil individual.{% endblocktrans %}
  • {% blocktrans %}Dados de Diagnóstico Ergonomico (Formulários): Respostas sobre o ambiente físico (temperatura, ruído, luminosidade), aspectos cognitivos (foco, conhecimento técnico) e comportamentais (pausas, uso de redes sociais).
    Finalidade: Calcular os índices de Efetividade Diária e gerar relatórios estatísticos agregados para fins acadêmicos e de pesquisa no âmbito da UFPB.{% endblocktrans %}

{% trans "2. USO DE COOKIES (DIREITO À INFORMAÇÃO)" %}

{% blocktrans %}Em respeito ao princípio da transparência da LGPD, informamos que a plataforma Ergo não utiliza cookies de marketing, anúncios, rastreamento comportamental ou serviços de publicidade de terceiros.{% endblocktrans %}

{% blocktrans %}Utilizamos exclusivamente Cookies Estritamente Necessários, que incluem:{% endblocktrans %}

  • {% blocktrans %}Cookies de Sessão: Temporários e essenciais para manter você logado de forma segura enquanto navega pelas páginas do sistema.{% endblocktrans %}
  • {% blocktrans %}Cookies de Segurança (CSRF Token): Mecanismos obrigatórios para blindar os formulários do sistema contra ataques externos e submissões maliciosas de dados.{% endblocktrans %}
{% trans "Nota Legal:" %} {% blocktrans %}Por serem componentes técnicos vitais para a estabilidade e segurança da aplicação, o uso destes cookies baseia-se na base legal de Execução de Serviço/Contrato e Legítimo Interesse, dispensando a exibição de banners invasivos de consentimento ("Aceitar/Recusar"), uma vez que o sistema não pode funcionar sem eles.{% endblocktrans %}

{% trans "3. BASE LEGAL PARA O TRATAMENTO DE DADOS" %}

{% blocktrans %}A plataforma Ergo trata os seus dados fundamentada nas seguintes hipóteses legais da LGPD:{% endblocktrans %}

  • {% blocktrans %}Execução de Contrato ou Procedimentos Preliminares (Art. 7º, V): Necessária para a prestação do serviço logado e entrega dos relatórios individuais.{% endblocktrans %}
  • {% blocktrans %}Realização de Estudos por Órgão de Pesquisa (Art. 7º, IV): Para fins estatísticos institucionais, garantindo que, sempre que possível, os dados sejam analisados de forma agregada.{% endblocktrans %}

{% trans "4. COMPARTILHAMENTO DE DADOS" %}

{% blocktrans %}O Ergo adota uma política rígida de não comercialização de dados. Suas informações nunca serão vendidas ou compartilhadas com empresas privadas ou para fins comerciais.{% endblocktrans %}

{% blocktrans %}O acesso aos dados brutos é restrito aos administradores do sistema e pesquisadores autorizados do projeto Ergo, com o objetivo estrito de aperfeiçoar a ferramenta e produzir conhecimento científico.{% endblocktrans %}

{% trans "5. SEGURANÇA DOS DADOS" %}

{% blocktrans %}Implementamos medidas técnicas e organizacionais adequadas para proteger os seus dados contra acessos não autorizados, perdas ou alterações:{% endblocktrans %}

  • {% blocktrans %}Todo o tráfego de dados entre o seu navegador e o nosso servidor é criptografado utilizando o protocolo HTTPS / SSL.{% endblocktrans %}
  • {% blocktrans %}O sistema roda em ambiente de contêiner e servidor isolado, com restrições rígidas de acesso à rede interna.{% endblocktrans %}
  • {% blocktrans %}Os logs de erro e acessos são monitorados continuamente para prevenir e mitigar vulnerabilidades.{% endblocktrans %}

{% trans "6. SEUS DIREITOS COMO TITULAR DOS DADOS" %}

{% blocktrans %}A LGPD garante a você controle sobre suas informações. A qualquer momento, você pode exercer os seguintes direitos entrando em contato com a administração da plataforma:{% endblocktrans %}

  • {% blocktrans %}Confirmar a existência do tratamento de dados e acessar as informações do seu perfil.{% endblocktrans %}
  • {% blocktrans %}Solicitar a correção de dados incompletos, inexatos ou desatualizados.{% endblocktrans %}
  • {% blocktrans %}Solicitar a exclusão definitiva de sua conta e dos dados a ela associados do nosso banco de dados ativo.{% endblocktrans %}
