# Relatório histórico — ERGO v4

Este arquivo é mantido apenas para rastreabilidade da versão anterior. A v4 introduziu a primeira camada de proteção, constraints e testes, mas a auditoria posterior encontrou lacunas no fluxo original.

A versão v5 adiciona, entre outros pontos:

- congelamento após aprovação;
- ciclos e snapshots de revisão;
- superusuário reconhecido sem promoção manual;
- privacidade reforçada em links públicos;
- checklist bloqueado após conclusão;
- Admin somente leitura para auditoria;
- documentação e validadores consolidados.

Para o estado atual, consulte [`RELATORIO_VALIDACAO_V5.md`](RELATORIO_VALIDACAO_V5.md) e [`../ALTERACOES_V5.md`](../ALTERACOES_V5.md).
